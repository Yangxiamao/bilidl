# bilidl

[中文](README.md) | [English](README.en.md) | **日本語**

**bilibili の動画ダウンローダーです。動画を mp4 で保存し、マルチスレッド・レジュームに対応。字幕と弾幕も一緒にダウンロードできます。** Windows ではダブルクリックで起動し、Web 画面から操作できます。

<p align="center"><img src="docs/images/web-ui.png" alt="bilidl の Web 画面：動画を解析したあと、画質（推定サイズ付き）、パート、保存先フォルダ、スレッド数を選ぶ" width="760"></p>

## インストール（Windows）

1. [Releases](https://github.com/Yangxiamao/bilidl/releases/latest) から `bilidl-vX.Y.Z.zip` をダウンロードし、好きなフォルダに展開します。
2. 中の `一键启动.bat`（ワンクリック起動）をダブルクリックします。初回起動時に Python や ffmpeg がなければ、自動でインストールするか聞かれます（Enter で同意）。
3. ブラウザでダウンロード画面が開きます：動画のリンクを貼り付け → 解析 → 画質と保存先を選択 → ダウンロード開始。

使用中は黒いコンソール画面を閉じないでください。720P 以上は[ログイン](docs/DOWNLOADER.md#登录720p-及以上需要)が必要です。bilibili の動画ページからワンクリックでダウンロードしたい場合は、[ダウンロード用の拡張機能](docs/DOWNLOADER.md#chrome-插件在-b-站视频页一键下载)も入れてください。

## 機能

- **速い**：マルチスレッドで分割ダウンロードし、より速い CDN ノードに切り替えます。作者の回線では約 2 MB/s から約 24 MB/s になりました。
- **レジューム**：途中で閉じても、次回は続きからダウンロードします。
- **パートごとに 1 つの mp4**：映像と音声を ffmpeg でまとめます。再エンコードはしません。
- **字幕と弾幕**：字幕（.srt）と弾幕（.ass）も一緒にダウンロードできます。字幕だけでも可能です。
- **コマンドライン**：`python bilidl.py BV1xxxxxxxxx -q 1080 -o D:\Videos`

詳しい説明（中国語：コマンドラインのオプション、Web 画面、自動起動、セキュリティ設計、高速化の仕組み）：[docs/DOWNLOADER.md](docs/DOWNLOADER.md)

## オンライン再生を快適にしたいだけなら

bilibili の Web プレーヤーが 4K や倍速再生で止まる場合は、同じ作者の [bilifast](https://github.com/Yangxiamao/bilifast) を使ってください。単体の Chrome 拡張機能で、このリポジトリのプログラムは不要です。
